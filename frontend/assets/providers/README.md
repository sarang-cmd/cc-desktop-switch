# Bundled provider logos

The following SVGs were extracted from the `logos` icon set distributed by [`@iconify-json/logos`](https://www.npmjs.com/package/@iconify-json/logos), version 1.2.19:

`anthropic.svg`, `cerebras.svg`, `cohere.svg`, `deepseek.svg`, `fireworks.svg`, `gemini.svg`, `groq.svg`, `kimi.svg`, `mistral.svg`, `ollama.svg`, `openai.svg`, `openrouter.svg`, `perplexity.svg`, and `together.svg`.

The icon set is released under CC0-1.0. Provider names and brand marks remain the property of their respective owners and are used only to identify provider presets. Logos are bundled locally so the app does not need to contact an image service to display them. Providers without a bundled mark continue to use the existing text or icon fallback.
