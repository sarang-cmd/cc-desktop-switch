What Junction does

Junction is a desktop application for configuring Claude Desktop to use API providers selected by the user. It does not provide a user account or cloud configuration synchronization service.

Information on your computer

The application stores provider settings, model routes, API keys, language and theme preferences, and other settings in its local configuration directory. The default location remains ~/.cc-desktop-switch for upgrade compatibility. CCDS_CONFIG_DIR can select another location. Local backups and diagnostic logs may also be created.

Provider requests

When you use a configured provider, Junction forwards requests to the endpoint you selected. Those requests may include prompts, model choices, and the authentication material required by that provider. The provider's terms and privacy practices apply to its processing. An optional upstream proxy routes requests through the address you configure.

Updates and downloads

The desktop app can check a GitHub Releases update manifest using its configured update URL. If you choose to install an update, the app downloads the release package and checks its SHA-256 value before opening the platform installer.

This static website is hosted by Vercel. Its homepage requests the latest release details from the GitHub API so it can show the current version and link directly to published files. Downloads are served by GitHub. Vercel's privacy terms apply to its hosting and service logs; GitHub's privacy terms apply to its API and download services. The project does not control either provider's server-side retention.

Diagnostics and support

Diagnostic exports are created when requested and are not automatically sent by Junction. An export may include app and operating-system versions, provider identifiers, sanitized endpoint details, model routes, local proxy state, and redacted recent logs. Review it before sharing; details can still reveal information about your setup.

Do not include API keys, access tokens, private endpoints, or unreviewed diagnostic exports in public issues.

Retention and requests

Configuration, backups, and logs remain on your computer and are subject to your local storage and deletion practices. The project does not currently provide a central user account or server-side profile.

Maintainer review required: confirm whether any support submissions or issue attachments are retained, identify a privacy contact, and document an appropriate request process before this draft is treated as policy.

Contact and changes

Maintainer review required: add an official privacy contact, the responsible legal entity, and a process for announcing material changes.
