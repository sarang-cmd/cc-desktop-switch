# Junction v1.0.28

This release introduces the Junction product identity and its first product website.

- Rebranded the desktop app, installer, application icon, release packaging, and project documentation to Junction.
- Added a responsive landing page with direct links to the latest Windows and macOS release assets.
- Pointed the app's update checker and in-app GitHub link at `sarang-cmd/cc-desktop-switch`.
- Preserved the existing local configuration directory, schema, single-instance identity, and upgrade path so current settings remain available.
- Added draft Terms and Privacy pages that clearly remain subject to maintainer and legal review.

The public repository currently remains `sarang-cmd/cc-desktop-switch`, so Junction links and update checks use that working repository path.
