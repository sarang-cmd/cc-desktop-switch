# Junction v1.0.29

This release refreshes the public Junction website with a restrained neumorphic visual system.

- Reworked the homepage and legal pages around cool neutral surfaces, selective raised and inset shadows, and a single muted blue accent.
- Kept the actual Junction model-routing screenshot as the main product visual.
- Preserved the responsive navigation, download links, release metadata, and legal draft disclosures.
- Removed neo-brutalist hard outlines, block shadows, and decorative orbit/window details.

This is a visual and presentation update. The desktop application behavior is unchanged from v1.0.28.
