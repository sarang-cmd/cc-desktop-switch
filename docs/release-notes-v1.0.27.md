# CC Desktop Switch v1.0.27

## English

This release refreshes the Neumorphic interface and adds locally bundled provider brand marks.

- Added local vector logos for the supported built-in providers that have matching assets. The logos work offline; custom or unlisted providers retain readable fallback icons.
- Refined provider logo sizing so both square marks and wordmarks fit the soft-surface controls.
- Continued the cool-neutral Neumorphic redesign across the app, including responsive layouts and clearer model-routing labels.
- Updated the README with genuine desktop and mobile screenshots captured locally using demo-only configuration.

### Upgrade notes

No provider migration is required. Existing API keys and provider settings are unchanged. Provider marks ship with the app and do not require runtime image-service requests.

## 简体中文

本次版本更新了 Neumorphic 界面，并为部分内置 provider 添加了本地品牌标志。

- 为有可用图标资源的内置 provider 添加本地矢量标志。离线时也能显示；自定义或暂未收录的 provider 继续使用清晰易辨的备用图标。
- 调整 provider 标志的尺寸，让方形图标和横向字标都能适配柔和的界面控件。
- 延续全应用的冷色中性 Neumorphic 视觉设计，完善响应式布局，并优化模型路由标签的可读性。
- 更新 README，加入使用演示配置在本地从真实应用界面截取的桌面端和移动端截图。

### 升级说明

无需迁移 provider。现有 API 密钥和 provider 设置保持不变。品牌标志随应用一起提供，运行时无需请求图片服务。
