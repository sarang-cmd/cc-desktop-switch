## Product

CC Desktop Switch is a desktop application for configuring Claude Desktop to use user-selected API providers. The application does not supply provider accounts, API credits, or third-party services.

## Provider services and credentials

Users supply their own API keys and select the endpoints they use. Requests are sent to those configured services, which are governed by their own terms, availability, pricing, and data practices. Users are responsible for reviewing those terms and protecting their credentials.

## Software license

Use and redistribution of the project source are governed by [LICENSE.txt](../LICENSE.txt). That license is separate from any final terms for distribution of packaged builds.
